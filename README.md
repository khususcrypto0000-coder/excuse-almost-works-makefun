# The Excuse That Almost Works

One line a gamer texts the boss to skip work during GTA 6 launch week.
It reads like a real hurried text: plain words, no setup, no explanation,
no signature — just a boring, specific workplace detail that almost
sounds believable. The mandatory fire safety refresher got moved online,
so it has to be done from home. The office safety training itself is the
reason you cannot come into the office.


verifies the file is byte-identical to the entry.
